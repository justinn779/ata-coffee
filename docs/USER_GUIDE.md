# 操作手冊

## 名詞說明

- **商品**：一支豆子或一種產品，例如「ATA 001 耶加雪菲」
- **規格**（舊稱品項）：商品底下實際販售、分開計算庫存與售價的包裝大小，例如 100g 包、200g 包、單包濾掛（業界常稱 SKU）
- **包材**：包裝用的袋子、標籤、濾掛袋等；規格可設定每包用哪些包材，分裝時自動扣除
- **分裝**：把烘好的熟豆裝成一包包商品，扣熟豆與包材、產生可以賣的成品
- **規格編號**：每個規格的代碼，例如 `SKU-001`；官網 API 與資料欄位中稱為 sku
- **編號都由系統自動產生**：新增咖啡豆、供應商、儲位、包材、品牌系列、商品、品項、生豆批次時都不用填編號，系統依序產生（咖啡豆 CF-001、供應商 SUP-001、儲位 L-001、包材 M-001、系列 S-001、商品 P-001、品項 SKU-001、生豆批次 GB-日期-序號），修改時沿用原本的編號

## 登入與介面

- 開啟網站後以管理員帳號登入（Firebase 帳號）。第一次使用時，部署指定的初始管理員登入後按「設定為初始管理員」。登入後進入「主畫面」，共 5 個主功能：咖啡豆（咖啡豆、生豆採購、烘豆、杯測、手沖、分裝、庫存、風味描述、整批盤點、庫存帳本）、訂單與顧客、商品與品牌（商品與品項、品牌系列與履歷）、成本與報表、系統設定。進入主功能後，上方的圓角按鈕可切換子功能；各頁標題左邊的 ← 回上一層（明細、新增頁回到列表；列表頁回到主畫面），右上角「主畫面」「功能選單」可直接跳到其他功能。主畫面只顯示圖示與短標題，滑鼠移到功能、數字或紀錄上會出現說明；待分裝、即將到期、未付款、待出貨只有在有資料時才顯示。
- 右下角月亮／太陽圖示切換暗色／亮色模式。
- 表格可搜尋、篩選、點欄位標題排序；手機上會改為卡片列表。
- 新增表單會自動暫存草稿（同一台裝置），離開未儲存頁面會提醒。手機上多段表單可用「上一步／下一步」分段填寫。
- 重要操作（確認付款、出貨、取消、異動庫存）都會跳出確認視窗，完成後右下角顯示結果。

### 忘記密碼與 Google 登入

- 忘記密碼：在登入頁輸入電子郵件後按「忘記密碼？」，到信箱（含垃圾郵件匣）點連結設定新密碼
- Google 登入：先用密碼登入，到「系統設定 → 個人帳號」按「綁定 Google 帳號」；之後登入頁可直接按「使用 Google 登入」

### 咖啡豆頁（以咖啡豆為主角）

「咖啡豆」→ 點一支豆子，同一頁就有這支豆子的全部資料。上方是流程：基本資料、1 生豆採購、2 烘豆、3 杯測、4 手沖、5 分裝、6 庫存。

- 沒點步驟時，每個步驟各列最近 5 筆；點某個步驟只看那一步的全部紀錄，再點一次回到全部。
- 每個步驟都有「＋ 新增」，每一列都有「修改」「刪除」，還有下一步的捷徑（例如生豆列的「烘豆」、烘豆列的「杯測」「手沖」「分裝」）。新增或修改完會回到咖啡豆頁。
- 可以從任意步驟開始：
  - 杯測、手沖：上方「豆子來源」選「沒有烘豆紀錄」，就能直接記在咖啡豆上（供應商樣品、外購熟豆）；填了烘焙日期會算烘後天數，這種紀錄不扣庫存。
  - 烘豆：可以不選生豆批次，直接選咖啡豆（生豆成本以 0 計、不扣生豆庫存），之後再到烘焙紀錄補選生豆批次；也可以按「＋ 新增生豆採購」，新增完自動回到烘豆表單。
  - 分裝：還沒有熟豆時，會出現「＋ 新增烘豆」，烘完回到分裝表單。
- 原本的生豆採購、烘豆、杯測、手沖、分裝、庫存列表頁都還在，在「咖啡豆」上方的分頁切換。

### 關聯不再擋住：先提醒，你決定

資料之間的關聯不會再擋住操作。遇到可能有影響的情況，系統會跳出黃色「⚠ 提醒」視窗說明會發生什麼，按「仍要繼續」就照樣存，按「先不要」就不存。例如：

- 刪除還有其他紀錄用到的資料（生豆採購已烘焙過、烘焙批次有杯測、咖啡豆有紀錄、訂單已收款…）：確認後只刪這一筆，其他紀錄保留原本的名稱與批號，標示「生豆採購已刪除」「烘焙紀錄已刪除」等。
- 庫存不夠（烘豆的生豆、分裝的熟豆或包材、訂單的成品）：確認後照樣記錄，庫存可以變成負數，之後補登採購或盤點修正。訂單缺貨的件數會先記著，補貨後在訂單按「修改」重新保留。
- 熟豆已分裝或出貨後再改烘焙重量、成本；已付款或已出貨的訂單再修改、取消、出貨未備妥的訂單等。

比較輕微的情況不會跳視窗，存檔後在右下角顯示黃色提醒（約 12 秒），例如：杯測、手沖時間早於烘焙時間（烘後天數會是負的）、事件時間順序不對、分段注水合計跟總水量不同、投入量超過烘豆機容量、熟豆批次跟商品設定的咖啡豆不同。

選單也會列出已用完的批次（標示「已用完」或「庫存不足」），不會因為沒庫存就選不到。

### 修改與刪除

舊資料都可以修改；修改後，所有用到它的資料會自動一起更新。刪除時如果還有別的紀錄用到它，會先提醒，確認後只刪這一筆。

- 烘焙批次：明細頁「修改」可改所有欄位。改生豆批次、投入或出爐重量、成本時，生豆以差額補扣或退回，熟豆庫存與單位成本自動調整；改烘焙時間時，杯測、手沖的「烘後天數」與熟豆到期日一起更新。生豆批次可以改成另一支咖啡豆的生豆，或改成「沒有生豆採購」；熟豆已分裝、出貨或被保留後再改重量與成本，會先提醒。「刪除」會退回生豆；這批還有杯測、手沖紀錄時，那些紀錄會保留並標示烘焙紀錄已刪除；熟豆已被使用時，庫存維持現狀、不退回生豆。
- 生豆採購：在生豆批次頁按「修改採購」或「刪除」。改入庫量時以差額調整庫存；改單價、運費時，熟豆還沒分裝出貨的烘焙批次會重算成本。已經烘焙過的生豆也能刪除（先提醒），烘焙紀錄保留原本的生豆批號。
- 分裝單：規劃中可「修改」數量、單包重量與日期（熟豆預留自動重算）；已完成的可「撤銷完成（修改）」，熟豆與包材退回庫存、成品作廢，回到規劃中再修改。成品已被訂單保留或出貨時會先提醒，確認後訂單的保留解除、回到待備貨。
- 訂單：未出貨（或已取消）時可「修改訂單」（品項、數量、折扣、運費），已付款也可以改（會提醒金額跟已收款不同）；已出貨的用「修改資訊」（顧客、收件、物流單號、備註）。任何訂單都可「刪除」，保留的成品會釋放回庫存；已出貨、已收款或有退貨時會先提醒。
- 杯測、手沖：紀錄頁「修改」或「刪除」，修改時也可以改選烘焙批次或改成「沒有烘豆紀錄」；有扣熟豆庫存的會自動沖銷再重扣。
- 主檔（咖啡豆、供應商、烘豆機、器材、儲位、包材、評分模板、風味詞彙、顧客、品牌系列、商品、品項、配方、分攤規則）：列表或明細頁可「編輯」「刪除」。改名稱時，烘焙、杯測、手沖、庫存、訂單上的名稱一起更新，已發布的 QR 履歷也會重新整理。已被使用的主檔也能刪除（先提醒），用到它的紀錄保留原本的名稱；咖啡豆也可以改用「封存」。
- 庫存帳本與盤點單是當時的紀錄，會保留原本的文字；帳本裡的異動只能沖銷，不能刪除。

### 平板烘豆即時紀錄

烘豆 →「平板即時紀錄」：
1. 選生豆批次（也可之後再選）、烘豆機、投入重量、入豆溫，設定火力／風門／鍋速的起始值與每按一次的加減量 → 按「入豆・開始計時」
2. 每 30 秒會有提示（聲音與畫面閃一下）：用畫面上的數字鍵輸入豆溫 → 按「記錄 m:ss」
3. 火力、風門、鍋速用 ＋／− 調整，會直接記在目前的時間點並沿用到之後
4. 回溫點、轉黃、一爆、一爆結束按下即記錄當下時間；按「下豆」停止計時
5. 點表格任一列可修改該時間點；按「下一步：填出爐重量並過帳」→ 補上出爐熟豆重量 → 過帳，紀錄點會存成這批的烘焙曲線
紀錄存在這台平板（重新整理、螢幕關閉都不會遺失），計時中會保持螢幕常亮。

### 列印出貨單、揀貨單

- 單張：訂單頁按「列印出貨單」，可切換是否顯示金額
- 批次：訂單列表按「列印可出貨訂單」（每張訂單一頁）或「列印揀貨單」（所有訂單品項依 品項編號＋批號彙總）

### 整批盤點

庫存中心 →「整批盤點」→ 選類別 → 輸入實盤數量（空白代表不盤點；可先按「全部帶入帳面數量」再修改差異的批次）→ 送出。差異會以盤點調整記入帳本，盤點紀錄可查看明細。

### 通知（Telegram／Gmail）

系統設定 →「通知」：
1. Telegram：在 Telegram 找 @BotFather 建立機器人，把金鑰貼到設定頁「驗證並儲存」→ 按「開始連結」→ 在 Telegram 對機器人傳送畫面上的 /start 驗證碼 → 按「完成連結」
2. Gmail：建議另開一個寄通知用的 Gmail，開啟兩步驟驗證並產生「應用程式密碼」；先在「通知項目」填寫寄件帳號與收件人並儲存，再貼上 16 碼密碼
3. 勾選每日彙整與即時通知項目，按「傳送測試通知」確認
金鑰與密碼只存在伺服器，網頁無法讀回；需要更換時直接輸入新的即可。

## 日常流程

### 1. 新增生豆採購
咖啡豆資料 →（若是新豆款先「新增咖啡豆」）→ 生豆採購批次 →「新增生豆採購」。填入採購重量、**實際入庫重量**、每公斤單價、運費。系統自動算出每克成本並入庫。

### 2. 開始新一批烘焙
烘焙中心 →「開始新一批」或「複製上一批」。選生豆批次、烘豆機，填投入與出爐重量；時間用 mm:ss（從入豆起算）。沒有的數值留空即可，系統不會推估。送出後：生豆扣除、熟豆入庫、失重率與 DTR 自動計算。

### 3. 匯入烘焙曲線
烘焙批次頁 →「匯入曲線」→ 選 CSV 或 Artisan `.alog` →「驗證並預覽」→ 必要時調整欄位對應 →「確認匯入」。錯誤會列出行號。同一檔案重複匯入會被拒絕。多批比較請用「疊圖比較」。

### 4. 杯測
咖啡豆頁「3 杯測」或杯測列表 →「新增杯測」，選烘焙批次；烘後天數自動計算。沒有烘豆紀錄的樣品，在「豆子來源」選「沒有烘豆紀錄」。可勾選「同步扣除熟豆庫存」。評分模板為 ATA 自訂系統（非 SCA 官方）。

### 5. 手沖
咖啡豆頁「4 手沖」或手沖列表 →「新增手沖」，或在紀錄頁「複製參數」；沒有烘豆紀錄也能記。分段注水合計需等於總水量。好的參數可「存為配方」（同名自動新版本）或「標記推薦」。

### 6. 分裝
先建商品（只要做一次）：「商品」→「＋ 新增商品」，填商品名稱、用哪支咖啡豆，再列出要賣的規格（例：100g、200g），每列填每包重量、售價，需要的話選袋子、標籤。其他設定（上架、現貨、原價）都用預設值，之後在商品頁可以修改。

分裝（一步完成）：在商品頁規格旁按「分裝」，或咖啡豆頁烘豆列的「分裝」，或「分裝紀錄」→「＋ 分裝」：選用哪批熟豆、裝成哪個規格、裝了幾包，按「完成分裝」。系統立刻扣熟豆與包材、產生成品，並算出每包成本。裝錯了在分裝紀錄頁按「撤銷完成」退回。

### 7. 建立手動訂單
訂單管理 →「建立手動訂單」：選顧客或填名稱，加入商品與數量。系統會立即保留成品；可接單後分裝的商品若沒現貨，會自動建立分裝單（訂單顯示「待分裝」）。庫存不足時會先提醒，確認後照樣建立，缺的件數補貨後再按「修改」重新保留。

### 8. 確認匯款
訂單頁 →「確認匯款」（可填末五碼）。重複按不會重複記錄。也可先「標記待確認」。

### 9. 出貨
訂單狀態為「可出貨」且已付款 →「標記出貨」，填物流與追蹤號碼、實際物流成本。系統扣除成品庫存。之後可「標記完成」。

### 10. 取消、退貨、退款
- 出貨前：「取消訂單」會釋放保留；若已付款可同時記錄退款。
- 出貨後：「辦理退貨」→ 商品進入**待檢**（不可售）→ 在退貨區按「合格入庫」或「報廢」。退款用「記錄退款」。

### 11. 查看庫存
庫存中心依生豆／熟豆／成品／包材分頁，顯示在庫、保留、可用。點批次可看完整帳本與保留紀錄。
- 杯測、試喝、樣品、報廢、盤點：批次頁「異動／盤點」。
- 記錯了：在帳本列按「沖銷」（原紀錄保留，另建反向交易）。
- 頁面上方會顯示「對帳正常」，若出現異常請停止操作並聯絡維護人員。

## 成本與報表
成本與報表頁選擇月份：銷貨毛利、訂單貢獻利益、營業淨利（管理用）分開列出，每項都附計算來源。估計成本會另外提示。期間費用（網站、租金等）在此新增。**本報表不能替代正式稅務申報。**

## 品牌系列與 QR 履歷
品牌系列頁可管理 ATA 001、002、Ati／Ato 特別版等。系列頁下方列出各包裝批次 QR Code，按「發布」後，掃描即可看到公開履歷（不含成本與顧客資料）。

## 系統設定
烘豆機、供應商、器材、評分模板、包材、儲位、稅務與預警、品牌素材上傳、CSV 匯出、完整 JSON 備份、管理員名單、前台 API 金鑰、操作紀錄。變更密碼在「個人帳號」。風味詞彙已移到「咖啡豆 → 風味描述」。

## 賞味與有效日期
- **烘後天數**：自烘焙日起算（臺北時間）。
- **建議養豆期／最佳風味觀察區間**：內部建議，可在咖啡豆設定預設、在烘焙批次覆寫。
- **商品標示有效日期**：依保存期限設定或分裝時手動指定，系統會記錄來源；**最佳風味不等於有效日期**。
