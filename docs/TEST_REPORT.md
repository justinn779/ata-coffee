## 安全規則（`tests/rules/security.test.ts`）

管理員可讀；未登入／非管理員不可讀（含顧客個資）；**管理員也不能從瀏覽器直接改庫存、帳本、訂單、稽核紀錄**；不能自行加入管理員；公開履歷只可讀已發布且不可列出；Storage 拒絕非管理員、錯誤副檔名、他人資料夾、錯誤類型。

## E2E（`tests/e2e`）

全部 45 個頁面（含 14 個設定分頁）與 10 個模組詳細頁可開啟且無 JavaScript 錯誤；建立訂單 → 確認匯款 → 出貨 → 追溯；超量下單被拒；曲線 CSV 上傳 → 預覽 → 匯入 → 重複拒絕；錯誤曲線顯示行號；表單必填驗證與建立；手機抽屜、卡片列表、無水平捲動、分段表單；未登入看不到資料；公開履歷不含成本與個資。
